# Changelog

## 0.4.0 — 2026-11-09

**Первый публичный выпуск `@apilki/yandex-market`.** Клиент Yandex Market Partner API для JavaScript и TypeScript — сторона продавца: заказы, каталог, цены, отчёты.

### Добавлено
- Типизированные методы по разделам Partner API с плоским списком аргументов (`campaignId` первым параметром в большинстве методов).
- TypeScript-типы всех операций и моделей; сборки CommonJS (`dist/`) и ESM (`dist/esm/`).
- Сохранение исходного именования полей из спецификации вендора — JSON-свойства не переименовываются.
